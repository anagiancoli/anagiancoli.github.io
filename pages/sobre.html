Ana Paula Müller Giancoli


Atualmente é professora no câmpus de Bragança Paulista do Instituto Federal de Educação, Ciência e Tecnologia de São Paulo (IFSP), na área de Programação e Banco de Dados.

Desde 2008, é professora efetiva e leciona para os cursos técnicos e tecnológicos em componentes curriculares relacionados com:

  • Lógica de Programação
  • Linguagem de Programação C
  • Linguagem de Programação Python
  • Introdução ao Desenvolvimento Web
  • Desenvolvimento Web Front-End
  • Análise Orientada a Objetos
  • Banco de Dados
  • Engenharia de Software

Possui formação acadêmica na área de Exatas:

  • Doutora em Engenharia Biomédica
  • Mestre em Engenharia Mecânica com ênfase em Informática
  • Licenciada em Computação
  • Pós-Graduada em Aperfeiçoamento em Formação Docente para a Educação a Distância
  • Especialista em Administração de Banco de Dados
  • Graduada em Tecnologia em Processamento de Dados
  • Graduada em Engenharia Civil
